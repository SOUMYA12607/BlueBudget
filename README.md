# BlueBudget
Personal expense tracker with monthly budgeting, analytics and PDF reports.
BlueBudget – Smart Expense Tracker

BlueBudget is a personal finance management web application designed to help users track their income, monitor expenses, manage monthly budgets and understand their spending habits.

It focuses on manual transaction tracking to encourage financial awareness while keeping users in control of their financial data.

Features

- Financial Dashboard: View total balance, monthly income and expenses.
- Transaction Management: Add, edit and delete income and expense records.
- Monthly Budget: Set a spending limit and monitor expenses through a progress bar.
- Transaction Filters: Search and filter transactions by category, type and month.
- Spending Analytics: Visualize monthly expenses and category-wise spending.
- Monthly Savings: Calculate net savings and savings rate.
- PDF Reports: Generate printable monthly financial reports with transaction details and expense summaries.
- Data Persistence: Uses browser LocalStorage to retain transaction records.

Why Manual Tracking?

BlueBudget uses manual transaction entry instead of automatic bank synchronization.

- Privacy: No bank account linking or banking credentials required.
- Financial Awareness: Recording expenses manually encourages mindful spending.
- User Control: Users choose which transactions to record and can edit them anytime.
- Flexibility: Supports cash transactions and other expenses that may not appear in bank statements.

Technologies Used

- HTML5 – Application structure
- CSS3 – Styling and responsive layout
- JavaScript – Functionality and calculations
- LocalStorage – Browser-based data persistence

Getting Started

1. Clone this repository:
   git clone https://github.com/your-username/BlueBudget.git
2. Open the project folder.
3. Open "index.html" in your browser.

No additional installation is required.

Data Storage

BlueBudget stores transaction records and budget settings in the browser's LocalStorage.

Note: Data is stored locally in the browser and is not synchronized across devices or browsers. Clearing browser data may remove saved records.
